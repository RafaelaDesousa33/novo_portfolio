# Meu Portfólio

Este é o meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades e projetos na área de Desenvolvimento Front-End.

## Tecnologias

* HTML5
* CSS3


## Sobre o projeto

Criei este portfólio para apresentar meus conhecimentos em desenvolvimento web e reunir meus principais projetos em um único lugar.

Busquei desenvolver uma interface moderna, organizada e responsiva, aplicando na prática conceitos de HTML, CSS e JavaScript.

## Objetivo

Meu objetivo é utilizar o portfólio para apresentar meu trabalho, demonstrar minhas habilidades e acompanhar minha evolução como desenvolvedora Front-End.
